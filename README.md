# Shubham Rana — Portfolio

A responsive portfolio site highlighting Shubham Rana's cloud infrastructure projects, technical skills, education, and contact information.

## View locally

Open `index.html` in a browser. The page is built with plain HTML, CSS, and JavaScript; it does not require a build step.

## Files

- `index.html` — page content and structure
- `style.css` — layout, responsive styling, and animations
- `script.js` — mobile navigation, reveal effects, and scroll progress
